# Auto-Memory Feature Notes

## 概要
Claude Code の auto-memory は、会話をまたいで情報を永続化する仕組み。

## このプロジェクトでの運用
- デフォルトの `~/.claude/projects/<slug>/memory/` ではなく、プロジェクト直下の `.claude/memory/` を使用
- git で管理されるため、別PCでも同じメモリを共有可能
- CLAUDE.md にメモリの読み書き先を `.claude/memory/` と明記してある

## 保存すべき内容
- 複数の会話で確認されたパターンや慣習
- アーキテクチャの決定、重要なファイルパス、プロジェクト構造
- ツールや作業フローに関するユーザーの好み
- 繰り返し発生する問題の解決策とデバッグの知見

## 保存すべきでない内容
- セッション固有のコンテキスト（現在のタスク詳細、進行中の作業）
- 不完全な情報（プロジェクトドキュメントで確認してから書く）
- CLAUDE.md の内容と重複するもの
- 単一ファイルを読んだだけの推測的な結論
